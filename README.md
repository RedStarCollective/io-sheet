# Iō Sheet

Interactive Cyberpunk RED character sheet for **Iō (Dr. Kōru Singh)**, played by Oak on RUSH.

Live at **https://redstarcollective.github.io/io-sheet/**

- `index.html`: the whole app (CSS and JS inline)
- `data/io.json`: Iō's data
- `data/ref.json`: rules text for implants and vehicle upgrades
- `img/`: art, body masks, posse and vehicle cut-outs

This copy is view-only. Planned next: read live data from Oak's Google Sheet through a Google Apps Script.
